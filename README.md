# Gatto Client

A modular Fabric client for **Minecraft 1.21.11**.

**Open GUI:** Right Shift

## Modules

**Movement**
- ToggleSprint
- Zoom

**Render**
- Fullbright
- NoHurtCam (real mixin)
- CustomCrosshair (size, gap, thickness, dot, outline, color)

**Combat**
- CPS Counter
- Attack Cooldown Indicator
- Target HUD

**HUD**
- FPS / Ping / Coordinates
- Armor durability
- Potion effects
- Keystrokes
- Clock + Session timer
- Watermark

**Misc**
- Sprint Status
- Chat Timestamps

## Features
- Modular system with keybinds + settings
- Persistent config
- Themes
- Notifications
- Click GUI with settings panel + keybind editor

## Build

```bash
./gradlew build
```

Jar will be in `build/libs/`.
